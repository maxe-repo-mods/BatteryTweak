# BatteryTweak

Adjust battery drain speed and charging station charge rate. Make batteries last longer or charge faster.

R.E.P.O. BepInEx mod. Host-side only.

## Install

Requires [BepInEx 5.x](https://thunderstore.io/c/repo/p/BepInEx/BepInExPack/).

Place `BatteryTweak.dll` in `BepInEx/plugins/`.

## Configuration

Edit `BepInEx/config/maxenterme.BatteryTweak.cfg` after first launch.

## Build

```
dotnet build -c Release
```
